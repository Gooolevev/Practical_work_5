# Алгоритмы на Java

Решения трёх задач. Требуется Java 17 или новее. Для запуска тестов нужен JUnit 5.

## 1. Сортировка слиянием

Ввод: n (от 0 до 100 000), затем n целых чисел.
Вывод: числа по неубыванию через пробел.
Встроенная сортировка не используется.

Пример: `6` и `5 1 4 2 8 3` → `1 2 3 4 5 8`.

## 2. Подсчёт инверсий

Ввод: n (от 0 до 100 000), затем n целых чисел.
Вывод: количество пар i < j, для которых a[i] > a[j].
Равные элементы не считаются инверсией. Результат хранится в long.

Пример: `5` и `2 4 1 3 5` → `3`.

## 3. Максимум одновременных встреч

Ввод: n, затем n пар целых чисел «начало конец», где начало < конец.
Вывод: максимальное количество встреч в один момент.
Интервалы полуоткрытые: [начало, конец). Встречи со стыкующимися границами не пересекаются.

Пример: `4` и пары `1 5`, `3 7`, `5 8`, `2 4` → `3`.

## Решения

Файлы решений находятся в `src/main`:

- `task_1` — рекурсивная сортировка слиянием.
- `task_2` — подсчёт инверсий при слиянии.
- `task_3` — сортировка начал и окончаний, затем проход двумя указателями.

Каждое решение работает за O(n log n) времени и использует O(n) дополнительной памяти.
Метод `solve` принимает потоки ввода и вывода; `main` запускает решение в консоли.

## Запуск

```bash
javac -encoding UTF-8 -d out src/main/*.java
java -cp out task_1
```

Для других задач замените имя класса на `task_2` или `task_3`.

## Тесты

Тесты находятся в `src/test`: `test_task_1.java`, `test_task_2.java`, `test_task_3.java`.
Для их запуска используйте JUnit 5 в IDE или JUnit Platform Console с явным выбором этих классов.

Простые JUnit 5 тесты проверяют примеры, пустой ввод (n = 0), повторяющиеся числа и стыки встреч.
